# Atividades de JavaScript

**Aluno:** Richard Monteiro

**Atividade:** Desenvolvimento de programas para cálculos de médias

## Descrição dos exercícios

1. **Média de notas** (`exercicio01.js`): solicita quatro notas de um aluno, calcula a média e apresenta o resultado.
2. **Média de vendas** (`exercicio02.js`): solicita o total de vendas de quatro semanas, calcula a média semanal e apresenta os valores com duas casas decimais.
3. **Consumo de energia** (`exercicio03.js`): solicita o consumo de quatro meses, calcula a média mensal e verifica se está dentro da meta de 150 kWh.

## Tecnologias utilizadas

- JavaScript
- HTML (apenas para executar no navegador)
- Visual Studio Code

## Como executar

1. Abra a pasta `Atividade 01` no computador.
2. Dê dois cliques no arquivo `.html` do exercício desejado (por exemplo, `exercicio01.html`) para abrir no navegador.
3. Responda às caixas de diálogo que aparecerem.
4. Aperte `F12` e abra a aba **Console** para ver o resultado.
